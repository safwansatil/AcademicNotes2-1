# Brief
Static vs. Dynamic: 
If you know exactly what your query is (e.g., SELECT name FROM users WHERE id = :id), static SQL (SQLJ) is faster because the database can pre-optimize the execution plan. If your query changes based on user input, you need dynamic SQL (JDBC).

### Update vs. Query
In JDBC, you must choose the right method based on what the SQL does:

- executeQuery(): Used for SELECT. It returns a ResultSet.

- executeUpdate(): Used for INSERT, UPDATE, DELETE, or CREATE. It returns an int representing the number of rows affected.
